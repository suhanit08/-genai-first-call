# GenAI First Call

## Project Overview
This project demonstrates how to build a Python development environment and connect it to a Generative AI model using the Google Gemini API.

## Technologies Used
- Python 3.14.4
- Visual Studio Code
- Google Gemini API
- Google GenAI SDK
- python-dotenv
- Git and GitHub

## Features
- Secure API key management using `.env`
- Environment variable loading
- Python integration with Gemini
- AI-generated text responses

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```

## Run the project

```bash
python first_llm_call.py
```

## Security
Never upload your `.env` file or API key to GitHub.
